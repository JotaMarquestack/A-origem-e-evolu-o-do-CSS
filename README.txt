GRUPO 07 - A ORIGEM E EVOLUÇÃO DO CSS

Projeto desenvolvido para a disciplina de Front-End.

TEMA
A origem e evolução do CSS.

OBJETIVO
Mostrar um pouco da história do CSS e como ele foi evoluindo
desde os primeiros estilos utilizados na Web até os recursos
mais modernos.

TECNOLOGIAS UTILIZADAS
- HTML5
- CSS3

ESTRUTURA DO PROJETO
- index.html
  Página principal do projeto.

- css/style.css
  Arquivo com os estilos da página.

- img/
  Pasta com as imagens utilizadas no projeto.

- README.txt
  Arquivo com informações básicas sobre o projeto.

SOBRE O PROJETO
A página apresenta uma linha do tempo com alguns dos principais
momentos da evolução do CSS. Também foi criada uma parte que
simula visualmente algumas características das páginas antigas
da Web, mostrando a diferença para os estilos utilizados
atualmente.
