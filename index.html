CAPÍTULO 01

O problema antes do CSS

Antes das folhas de estilo, estrutura e aparência estavam muito mais misturadas.

01

Antes do CSS

As primeiras páginas eram documentos com poucos recursos visuais. Para mudar a aparência, eram usados elementos como <font> e <center>, além de tabelas para estruturar partes do layout.

02

As consequências

A repetição de estilos deixava o código maior e dificultava alterações. Uma simples mudança visual poderia exigir edições em várias páginas.

03

A ideia do CSS

A proposta foi separar estrutura e apresentação. Dessa maneira, um arquivo de estilos poderia controlar a aparência de diferentes documentos.

1994
O início da proposta

Håkon Wium Lie apresenta a ideia das folhas de estilo

A proposta surge no CERN e, junto com o trabalho de Bert Bos, evolui até se transformar em uma tecnologia voltada à separação entre conteúdo e apresentação.

CAPÍTULO 02

Linha do tempo

Dos primeiros padrões às ferramentas usadas para construir layouts atuais.

1994

Proposta do CSS

Håkon Wium Lie apresenta a ideia das folhas de estilo no CERN, iniciando uma proposta que buscava separar conteúdo e apresentação.

1996

CSS1

O W3C publica o primeiro nível do CSS, trazendo propriedades para fontes, cores, margens, bordas e alinhamento de texto.

1998

CSS2

O CSS2 amplia os recursos de posicionamento, tipos de mídia, seletores e organização visual dos elementos.

1999

Início do CSS3

A evolução passa a caminhar em direção a módulos independentes, permitindo que diferentes partes do CSS avancem separadamente.

2011

CSS 2.1 e novos módulos

O CSS 2.1 organiza e corrige pontos da especificação anterior, enquanto módulos como Color e Selectors continuam avançando.

2012

Media Queries

As media queries permitem adaptar estilos de acordo com características da tela, contribuindo para páginas responsivas.

2017+

Flexbox e Grid

Flexbox facilita o alinhamento em uma dimensão, enquanto Grid permite organizar elementos em linhas e colunas.

HOJE

CSS moderno

Recursos como Custom Properties, Container Queries, :has() e @layer ampliam ainda mais as possibilidades do CSS.

CAPÍTULO 03

O modelo modular do CSS3

O CSS moderno é dividido em diferentes módulos e áreas de especificação.

01

Selectors

Permitem selecionar elementos de maneira mais precisa.

02

Color

Define formas de trabalhar com cores e transparências.

03

Backgrounds & Borders

Permite criar fundos, bordas, gradientes e sombras.

04

Media Queries

Aplicam estilos de acordo com características da tela.

05

Flexbox

Organiza elementos em uma dimensão com flexibilidade.

06

Grid

Organiza layouts utilizando linhas e colunas.

CONCLUSÃO

Da necessidade à evolução

O CSS surgiu para resolver a mistura entre conteúdo e aparência. Com o passar dos anos, deixou de oferecer apenas recursos básicos de apresentação e passou a reunir ferramentas para criar layouts responsivos, organizados e cada vez mais completos.
